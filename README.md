# Visual Components Blenderer - Sejfo Edition
## About
This project is built on-top of Visual Components' [Blenderer add-on by Emeritus](https://forum.visualcomponents.com/t/blender-addon-blenderer/773)

The aim is to make it produce renders that better align with the style of renders we at Sejfo tend to use in concepts.

# BlenderProps
## About
BlenderProps is a helper add-on for Visual Components that creates a new tab in your component with properties that will control certain object-level Blender settings.

# How to install
Download the add-on zip-files.
Unzip into the VC commands folder which usually is found in  C:\Users\\<username>\Documents\Visual Components\4.10\My Commands\Python 2
